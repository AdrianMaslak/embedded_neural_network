# Dataset

Synthetic 60×80 8-bit grayscale PNGs, one shape each: Circle, Square, Triangle, Figure8.
Generated by [`../gen_shapes.py`](../gen_shapes.py) with fixed seeds.

| Split | Images per class | In the repository |
|---|---|---|
| train | 1500 | no – regenerate with `python gen_shapes.py` |
| val | 300 | no – regenerate |
| test | 300 | **yes** – the 1200 images behind every reported result |

* `labels.csv` – every image of every split with its generation parameters (size, angle, line
  thickness, filled, position, background/foreground level, blur, noise).
* `preview.png` – sample grid.

Each split and class comes from its own random stream, so the splits never share an image and
`gen_shapes.py` recreates exactly the same files.
